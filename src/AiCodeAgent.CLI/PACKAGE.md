# Vibe Coding Hub CLI

`aiagent`: the command-line tool of [Vibe Coding Hub](https://github.com/AIHelpers/vibe-coding-hub), an open-source AI
coding agent. Bring your own model (OpenAI, Anthropic, Ollama, LM Studio or any OpenAI-compatible API), run teams of
agents in flows, and review every change as a diff before it is applied.

```bash
dotnet tool install -g VibeCodingHub.Cli
aiagent --help
```

Requires the .NET 10 runtime. Self-contained downloads (no .NET needed) are on the
[releases page](https://github.com/AIHelpers/vibe-coding-hub/releases/latest).
